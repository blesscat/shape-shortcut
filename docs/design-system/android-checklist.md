# Android 真機驗證（PR 後）

使用者已選擇先建立 draft PR，再使用 Android 檢查。本文件是待執行清單，
不是已通過的驗收證據。本次交付 CAD 與 Playground 的透明抽屜；沒有可測的
正式 split/divider，以下結果也不能當作 split promotion 的通過證據。

## 開始前

從 PR 的實際預覽站進入，不使用正式站當作本分支的驗證。記錄預覽網址、
PR commit、手機型號、Android 版本、瀏覽器與版本。若 PR 沒有提供可開啟的
預覽網址，需另行安排預覽；建立 PR 本身不等於部署完成。

## 約 10–15 分鐘的操作

1. 開啟方盒 `/zh-Hant/cad/opengrid-stackable-box/`。等待模型完成，旋轉與縮放，
   開啟、關閉參數抽屜。確認模型方向與縮放不跳動，抽屜仍能透見模型，
   方向指示器與下載操作沒有互相遮住。
2. 開抽屜並點尺寸欄位叫出鍵盤。捲到較下方欄位，再輸入低於欄位最小值的值。
   確認目前欄位、錯誤文字與收合控制可達；關閉鍵盤後輸入正確值，等待更新，
   確認錯誤解除、STL 下載恢復可用。不要把舊模型誤認為已更新結果。
3. 開啟高層架 `/zh-Hant/cad/opengrid-openconnect-shelf/`，重做鍵盤、長面板捲動，
   在直向與橫向切換。確認沒有水平頁面溢出或無法取用的控制。
4. 開啟 `/zh-Hant/cad/playground/`，加入兩個元件，切換選取、編輯其中一個，
   確認修改只作用於選中物件。測試場景旋轉、物件點選、抽屜內捲動；手勢
   不應同時拖曳場景與面板。確認場景匯入／匯出入口仍可達。
5. 切換明／暗模式與 English，再至少重做一次鍵盤和橫向檢查。
   文字、錯誤、disabled 按鈕應可讀，長標籤不應截掉差異。
6. 返回模型選擇與文件，確認手機選單、卡片詳情關閉、章節展開及組裝教學
   正常可用。長視窗能捲到最後，不把頁面鎖在無法捲動的狀態。
